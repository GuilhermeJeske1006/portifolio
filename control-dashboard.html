Sistema Control GJ

Informações do projeto

Descrição do projeto

Criação do sistema Control GJ, responsável pela criação de orçamentos e recibos. Possui integração com assinaturas mensais (SaaS). O projeto foi desenvolvido com Laravel e Livewire, utilizando banco de dados MySQL.
