Horarius

Informações do projeto

  • Categoria: Sistema web
  • Tecnologia: Laravel 12, Livewire 4, Flux UI, Fortify, Filas (Jobs), API Nuvem Fiscal, DomPDF
  • Data do projeto: 2026

Descrição do projeto

O Horarius é um sistema de controle de horas trabalhadas. Os funcionários registram o ponto por local de trabalho, e o gestor acompanha as horas de cada pessoa.

A partir das horas lançadas, o sistema emite a nota fiscal de serviço (NFS-e) automaticamente pela API da Nuvem Fiscal, facilitando o fechamento e o pagamento de prestadores de serviço.

Principais funcionalidades

  • Registro de ponto pelo próprio funcionário ("Meu ponto")
  • Cadastro de locais de trabalho e funcionários
  • Lançamento e edição de registros de horas
  • Emissão de NFS-e integrada à Nuvem Fiscal, com consulta de status em fila
  • Visualização da nota fiscal em PDF
  • Autenticação com Fortify e 2FA
